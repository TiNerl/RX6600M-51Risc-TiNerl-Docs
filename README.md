# O que foi feito até agora?
### Como eu precisava de uma placa de vídeo Overclockada para rodar ambos jogos e modelos de IA me vi
### na obrigação de trocar a bios padrão dela por uma semelhante para liberar o controle dos clocks que
### fora anteriormente trancada permanentemente pela AMD (por motivos que até hoje não compreendo) 
### consequentemente me obrigando a dedicar um repositório para armazenar minhas tranqueiras.

### e a da RX6600 da marca Pulse. Quanto as configurações e programas utilizados planejo especificar no futuro
### quando tiver mais tempo, no momento é o que tem para hoje (15/09/2026).
